## Implementation choices

- `evaluate()` returns the existing `ProbeReport` with comparison/quality metadata rather than adding a second public result wrapper. This preserves the documented facade return type.
- `check --no-compare` makes intentionally unbaselined checks explicit, including CI without restoration inputs.
- Workflow helpers live in the installed package, so a reusable workflow does not depend on helper files existing in the caller repository.
- Pytest uses public stash storage and opt-in session enforcement instead of private configuration attributes or synthetic test items.
- Source archives include workflow files referenced by packaged regression tests.

## Reproduction

From an installed source checkout:

```bash
uv sync --locked --dev --python 3.12
uv run pytest tests/ --run-integration -q
uv run ruff check src/
uv lock --check --offline
uv build
```

Use a separate Python 3.11 environment for the second matrix result. The local HTTP cases need permission to bind localhost. Workflow JavaScript tests need Node; they are explicitly marked as unavailable if Node is absent.

The actual artifact build used a temporary environment containing Hatchling and the Python `build` tool:

```bash
python -m build --no-isolation
```

For a base-only installed-artifact check:

```bash
uv venv /tmp/longprobe-v020-wheel --python 3.12
uv pip install --python /tmp/longprobe-v020-wheel/bin/python dist/longprobe-0.2.0-py3-none-any.whl
/tmp/longprobe-v020-wheel/bin/python -I examples/verify_v020_release.py
```

The verifier checks the installed package outside the checkout, optional-SDK/test-dependency absence, startup behavior, actual HTTP CLI operations, baseline rejection/preservation, report rendering, local CI feedback, distribution identity, source archive contents, and hashes.

Workflow validation used the official actionlint 1.7.12 Linux binary after verifying its release checksum. The downloaded archive SHA-256 was `8aca8db96f1b94770f1b0d72b6dddcb1ebb8123cb3712530b08cc387b349a3d8`. Actionlint and all temporary verification environments remain outside the repository.
